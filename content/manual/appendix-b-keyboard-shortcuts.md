# Appendix B — Keyboard Shortcuts

The complete shortcut map for both editions. Open the in-app list any time from **Help ▸ Keyboard Shortcuts** (⌘? / Ctrl+?).

> Modifier symbols: ⌘ Command · ⌥ Option/Alt · ⇧ Shift · ⌃ Control. As a rule, Windows uses **Ctrl** where macOS uses **⌘**, and **Alt** where macOS uses **⌥**.

## Running the show

These bare keys work anywhere in the main window. They stand aside while you're typing in a text box and come back as soon as you click outside it; they never act while a dialog is open or while a modifier key is held.

| Action | macOS | Windows |
|---|---|---|
| Next slide | → or Page Down | → or Page Down |
| Previous slide | ← or Page Up | ← or Page Up |
| One row down / up in the slide grid | ↓ / ↑ | ↓ / ↑ |
| Play / pause the live video | Space | Space |
| Toggle Blank | ⌘B | **B** |
| Take | ⌘⏎ | — *(TAKE button)* |
| Delete the selection (asks first) | Delete | Delete |
| Answer the Delete question | Return = Delete · Esc = Cancel | Enter = Delete · Esc = Cancel |
| Clear Quick Screen | Esc | — *(Clear screen button)* |

A presentation clicker's Page Down / Page Up buttons move one slide on both editions.

> The live audience output window on Windows also accepts **→ / Space / Page Down** to advance, **← / Page Up** to go back, **B** to blank and **Esc** to close while it has focus.

## ⚠️ Shortcut differences to watch

- **Ctrl+L** on Windows toggles the **Audience Screen**. The nearest macOS equivalent (⇧⌘L) instead means **Toggle Listening** — so the same-looking chord does different things per platform. On Windows, **Toggle Listening has no keyboard shortcut** (click the LISTENING pill).
- **Blank** is plain **B** on Windows but **⌘B** on macOS.
- **Take** (⌘⏎), **Open Presentation** (⌘O), **Add files** (⇧⌘I) and **Undo Scene** (⌥⌘Z) exist on macOS only.
- **Start/Stop Remote Server** (Ctrl+R) exists on Windows only — the macOS remote is always on.

See [Preferences, Shortcuts & Menus](11-preferences-shortcuts.md) for the full menu map, and [Appendix A](appendix-a-platform-differences.md) for feature-level differences.
